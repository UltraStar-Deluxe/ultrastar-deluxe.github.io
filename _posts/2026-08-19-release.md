Version 2026.8.1 has been released.
Downloads are available from [github](https://github.com/UltraStar-Deluxe/USDX/releases/tag/v2026.8.1)
and [flathub](https://flathub.org/apps/eu.usdx.UltraStarDeluxe).

## Enhancements
* In List mode, selecting a song is no longer restricted to just the cover image #1273
* Improve texture quality when downsizing #1213 #1396

## Bug Fixes
* Fix P1 note colors if the Editor was open before singing and the last note was a golden note #1392
* Fix mouse state inverting after playing a medley with an even number of songs #1352
* Fix highscores not being shown for P1 difficulty until any song was played if players are selected after song selection #1367
* Respect START and END for previews #1354
* Fix video sync after toggling backgrounds when a song uses START #1398
* Fix Mac build #1399
