Version 2026.10.0 has been released.
Downloads are available from [github](https://github.com/UltraStar-Deluxe/USDX/releases/tag/v2026.10.0)
and [flathub](https://flathub.org/apps/eu.usdx.UltraStarDeluxe).

## Breaking changes
* Avatars, themes, plugins and highscore plugins are detected from home/application directories. Breaking is that highscore plugins on Linux will no longer be read from the installation directory #1422

## Enhancements
* Duets save highscores. Can be disabled in Options - Advanced #1409

## Bug Fixes
* Fix crash on invalid `#VERSION` #1434
* Fix SelectSlide color for colorized textures #1439
* Fix fullscreen glitches #1447

## Other Changes
* Implement crash stacktraces on Mac #1428 #1435
* Codesign Mac builds #1431
* Support sdl2-compat on Mac #1432
* Cleanup temporary files on Mac #1437
* Remove Lazarus-related files #1442
* Update Italian translation #1438 #1445
* Update Icelandic translation #1443
* Document that Lua 5.5 is supported #1448
* Use correct name for MacOS app bundle #1449
* Make compiler flags work on Windows and Intel Macs #1452
