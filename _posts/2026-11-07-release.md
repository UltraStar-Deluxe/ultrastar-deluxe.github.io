Version 2026.11.0 has been released.
Downloads are available from [github](https://github.com/UltraStar-Deluxe/USDX/releases/tag/v2026.11.0)
and [flathub](https://flathub.org/apps/eu.usdx.UltraStarDeluxe).

## Bug Fixes
* Fix some scores not being saved if the last line was entirely freestyle #1467
* Fix sound effects on Linux/Mac #1460
* Fix some songs not being loaded if their metadata contains certain Chinese characters #1463

## Other Changes
* Fail Mac build if external library function does not exist #1455
* Use autotools on Windows #1454
* Update Windows DLLs #1461
* Avoid duplicate PrintScreen captures with the Windows hotkey #1457
* Replace legacy GitHub issue template with issue forms #1464
